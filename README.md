This repository Implements Random Test Pattern Generators (LFSR, Bit-Swapping LFSR, Internal-External LFSR, Weighted Random Pattern Generator) in System Verilog using Xilinx Vivado.

The BSLFSR Folder contains the following :-
1. "bslfsr.sv" - this file contains the design code of Bit-Swapping Linear Feedback Shift Register.
2. "bslfsr_tb.sv" - this file contains the testbench code of Bit-Swapping Linear Feedback Shift Register.

The IELFSR Folder contains the following :-
1. "ielfsr.sv" - this file contains the design code of Internal-External Linear Feedback Shift Register.
2. "ielfsr_tb.sv" - this file contains the testbench code of Internal-External Linear Feedback Shift Register.

The LFSR Folder contains the following :-
1. "lfsr.sv" - this file contains the design code of Linear Feedback Shift Register.
2. "lfsr_tb.sv" - this file contains the testbench code of Linear Feedback Shift Register.
